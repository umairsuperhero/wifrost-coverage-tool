## Architecture facts (so you don't repeat past confusion)
- **Repo:** this directory (remote `github.com/umairsuperhero/wifrost-coverage-tool`).
- **Frontend:** Next.js 16 / React 19 in `frontend/` — a pure client-side SPA (no Next API
  routes, no Vercel serverless functions). Calls the backend via
  `API_BASE = process.env.NEXT_PUBLIC_API_URL` (see `frontend/app/page.tsx:5`,
  `frontend/vercel.json`, `frontend/.env.local` = `http://127.0.0.1:8000`).
  Vercel: `main` → production (`https://wifrost-coverage-tool.vercel.app`), every branch
  push → a preview. Components live in `frontend/components/` (NOT `frontend/app/components/`).
- **Backend:** FastAPI (`api.py`, entrypoint `uvicorn api:app`), Python 3.9 venv at `venv/`.
  Prod = **Google Cloud Run** service `wifrost-api`, region `northamerica-south1`,
  `--cpu 1 --memory 2Gi --timeout 120`, scales to zero, deployed via `cloudbuild.yaml`.
  **Prod runs the OLD `main` build (Okumura-Hata).**
- **CRITICAL:** the feature-branch **backend is deployed nowhere.** The Vercel preview
  frontend (new UI) currently calls the **prod** Cloud Run backend = old `main` code — so
  the preview does NOT exercise the new ITM Longley-Rice physics or recent backend fixes.
  **To validate the new UI you must deploy the feature-branch backend to a separate
  non-prod Cloud Run service and point the preview at it.**
- **`OPENTOPOGRAPHY_API_KEY`** is read only by the backend (`os.getenv` in `api.py`) on
  Cloud Run. It is **NOT in `cloudbuild.yaml`** (set out-of-band) → a clean redeploy can
  silently regress the SRTM "flat-earth" bug. Bake it in (Secret Manager + `--set-secrets`).
  The copy set on Vercel is **inert** (frontend never reads it) and can be deleted.

### 4. CPE list performance at 500 (Finding #2) — measure before building

`content-visibility: auto` (it did NOT skip off-screen cards even at 600 items here).

### 5. Phase 1 — physics correctness (the big remaining item)

direction). Also fix: CPE MDT vertical angle ignores terrain ASL (`api.py:635` area); ITM
failures silently fall back to optimistic FSPL; built-up double-penalty (urban env + clutter).
